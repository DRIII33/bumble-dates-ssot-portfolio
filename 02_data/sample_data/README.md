### Sample Data for BigQuery Load

This directory contains CSV files generated by `02_data/01_generate_synthetic_data.py`.
These files are intended to be uploaded to Google BigQuery as staging tables within the `driiiportfolio.bumble_portfolio` dataset.

**File List:**
- `users.csv`
- `verifications.csv`
- `events.csv`
- `matches.csv`
- `messages.csv`
- `payments.csv`

**Instructions for BigQuery Load:**
1.  Ensure you have a BigQuery project (`driiiportfolio`) and dataset (`bumble_portfolio`) set up.
2.  In the BigQuery UI, navigate to your `bumble_portfolio` dataset.
3.  Click on 'Create table'.
4.  Select 'Upload' for the Source, and choose one of the CSV files from this directory.
5.  For each file, name the table with the prefix `stg_` (e.g., `stg_users` for `users.csv`).
6.  Ensure 'Auto detect' schema is enabled or manually specify the schema based on `02_data/00_schema.md`.
7.  Repeat for all CSV files.
