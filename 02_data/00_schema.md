### Synthetic Data Schema Specification

This document outlines the schema for the synthetic datasets generated by `02_data/01_generate_synthetic_data.py`.

#### 1. `users.csv`
**Description:** Contains core user profile information.
| Field Name             | Data Type | Description                                             |
| :--------------------- | :-------- | :------------------------------------------------------ |
| `user_id`              | OBJECT    | Unique identifier for each user.                        |
| `signup_ts`            | OBJECT    | Timestamp of user signup (ISO format).                  |
| `country`              | OBJECT    | User's country.                                         |
| `zip_code`             | INT64     | User's zip code.                                        |
| `gender`               | OBJECT    | User's gender (female, male, nonbinary).                |
| `age`                  | FLOAT64   | User's age (can be null).                               |
| `intent_level`         | OBJECT    | User's declared intent (casual, intentional, friendship).|
| `is_paying`            | INT64     | Binary flag: 1 if paying, 0 otherwise.                  |
| `initial_right_swipe_rate` | FLOAT64   | Initial right swipe rate.                               |
| `is_pruned`            | INT64     | Binary flag: 1 if user was pruned, 0 otherwise.         |

#### 2. `verifications.csv`
**Description:** Records selfie verification attempts and status.
| Field Name             | Data Type | Description                                             |
| :--------------------- | :-------- | :------------------------------------------------------ |
| `user_id`              | OBJECT    | Unique identifier for the user.                         |
| `verification_attempted` | INT64     | Binary flag: 1 if verification was attempted, 0 otherwise. |
| `verification_passed`  | INT64     | Binary flag: 1 if verification passed, 0 otherwise.     |
| `verification_ts`      | OBJECT    | Timestamp of verification (ISO format, can be null).    |

#### 3. `events.csv`
**Description:** Detailed user interaction events on the platform.
| Field Name             | Data Type | Description                                             |
| :--------------------- | :-------- | :------------------------------------------------------ |
| `event_id`             | OBJECT    | Unique identifier for each event.                       |
| `user_id`              | OBJECT    | Identifier for the user performing the event.           |
| `event_type`           | OBJECT    | Type of event (session_start, profile_view, swipe, date_suggestion, match, message_sent). |
| `event_ts`             | OBJECT    | Timestamp of the event (ISO format).                    |
| `device`               | OBJECT    | Device used (iOS, Android, Web, can be null).           |
| `app_version`          | OBJECT    | Version of the application.                             |

#### 4. `matches.csv`
**Description:** Records match events between users.
| Field Name             | Data Type | Description                                             |
| :--------------------- | :-------- | :------------------------------------------------------ |
| `match_id`             | OBJECT    | Unique identifier for the match.                        |
| `user_id`              | OBJECT    | Identifier for the user who initiated the match (or was matched).|
| `partner_id`           | OBJECT    | Identifier for the matched partner.                     |
| `match_ts`             | OBJECT    | Timestamp of the match (ISO format).                    |
| `match_source`         | OBJECT    | Source of the match (dates or swipe).                   |
| `partner_verified`     | INT64     | Binary flag: 1 if partner is verified, 0 otherwise.     |

#### 5. `messages.csv`
**Description:** Records messages sent within matches.
| Field Name             | Data Type | Description                                             |
| :--------------------- | :-------- | :------------------------------------------------------ |
| `message_id`           | OBJECT    | Unique identifier for the message.                      |
| `match_id`             | OBJECT    | Identifier for the match this message belongs to.       |
| `sender_id`            | OBJECT    | Identifier for the user who sent the message.           |
| `text`                 | OBJECT    | Placeholder for message content.                        |
| `sentiment`            | OBJECT    | Sentiment of the message (positive, neutral, negative). |
| `message_ts`           | OBJECT    | Timestamp of the message (ISO format).                  |

#### 6. `payments.csv`
**Description:** Records user payment transactions.
| Field Name             | Data Type | Description                                             |
| :--------------------- | :-------- | :------------------------------------------------------ |
| `payment_id`           | OBJECT    | Unique identifier for the payment.                      |
| `user_id`              | OBJECT    | Identifier for the user who made the payment.           |
| `amount`               | FLOAT64   | Payment amount.                                         |
| `currency`             | OBJECT    | Currency of the payment (e.g., USD).                    |
| `payment_ts`           | OBJECT    | Timestamp of the payment (ISO format).                  |
| `payment_method`       | OBJECT    | Method of payment (card, apple_pay, google_pay).        |
